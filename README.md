# 日历拼图

一个可以在浏览器里玩的日历拼图，灵感来自实体的木质日历拼图。把 10 块木块全部放进木板，只露出当天的「月」「日」「星期」三格，就算成功。

整个游戏只有一个 HTML 文件，用原生 JavaScript 和 SVG 编写，不需要框架，也不需要构建。

## 开始游戏

下载或克隆仓库后，用浏览器打开 `calendar-puzzle.html`。

字体从 Google Fonts 加载。没有网络时会改用系统字体，不影响游戏功能。

## 玩法

| 操作 | 方式 |
| --- | --- |
| 移动木块 | 拖动，靠近格子时自动吸附 |
| 顺时针旋转 | 轻点木块、点「旋转」按钮或按 `R` |
| 翻面 | 右键、Shift + 点击、点「翻面」按钮或按 `F` |

- **目标日期**：默认是今天，也可以用日期选择框换成其他日期。
- **标出目标格**：用红色虚线框标出需要露出的三格。
- **看答案**：自动摆出当前日期的一种解法，同时停止计时。
- **重来**：把所有木块放回初始位置，并将计时清零。

计时从第一次移动或旋转木块时开始，拼好后停止。如果木块放满了但日期不对，页面会提示实际露出的是哪三格。

## 原理

木板共有 50 格：12 格月份、31 格日期和 7 格星期。10 块木块包括 3 块四格和 7 块五格，一共覆盖 47 格，所以全部放好后正好空出 3 格。

「看答案」使用回溯搜索：每次找到第一个未覆盖的格子，依次尝试尚未使用的木块及其各种朝向，走不通就撤回并换下一种摆法。用这个求解器测试 2024 年全部 366 个日期，每天都能找到解。

## 文件

- `calendar-puzzle.html`：游戏的全部代码，包括样式、木板绘制、交互和求解器。
